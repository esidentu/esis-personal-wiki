# FTMBA 200S Syllabus

This syllabus outlines the course structure, materials, and expectations for FTMBA 200S: Data and Decisions, a seven-week intensive course covering statistical inference, regression models, and data analysis techniques. The course emphasizes deep understanding over formula memorization and incorporates AI model interfaces for decision-making.

## Key Details

['Course covers statistical tests, confidence intervals, and regression models.', 'Focuses on interpretation and inference rather than formula memorization.', 'Utilizes AI model interfaces (Gemini, ChatGPT, Claude) for data analysis.', 'Requires data work using statistical software (Stata, Excel, R, SAS, SPSS, Matlab, Python).']
