# Course Assessment Components

This page outlines the grading breakdown for the course, including participation, attendance, quizzes, exams, and a group project, detailing the weighting and requirements for each component.

## Key Details

- Participation: 30% (Attendance, Instructor Rating, Peer Review)
- Attendance: Mandatory, measured through iClicker quizzes.
- Quizzes: 10% (iClicker quizzes, lowest score dropped)
- Exams: Midterm (15%) and Final (20%)
- Group Memo: Short memo project
