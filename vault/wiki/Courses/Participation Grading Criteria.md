# Participation Grading Criteria

This page details the criteria used to assess student participation, emphasizing relevance, progress, facts, and course concepts, along with the instructor's cold-calling policy.

## Key Details

- Relevance: Comment is on point and related to the case or topic.
- Progress: Comment moves the class forward.
- Facts: Comment points to facts from readings, lecture, or experience.
- Course Concepts: Comment uses core concepts to make a point.
- Cold Calling: Instructor may call on students, no penalty for unpreparedness.
